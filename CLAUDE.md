# CLAUDE.md — правила проекта «live-guide»

## Что это
PWA — калькулятор стоимости путешествия по Узбекистану. Пользователь выбирает уровень
(эконом / средний / люкс), количество человек, дату начала, города и число ночей в каждом —
и видит итоговую сумму с разбивкой. Это ядро продукта.
Вкладки «Маршруты», «Проживание», «Питание» — витрина: карточки с фото и текстом,
некликабельные, без переходов внутрь. Карты в приложении НЕТ.
Устройства: iPad (главное), iPhone, десктоп. Установка на домашний экран, работа офлайн.

## Стек
Vite + Vue 3 + TypeScript, vite-plugin-pwa, vue-router, pinia. Статика, своего сервера нет.
Git → GitHub → Vercel. [ВНИМАНИЕ] Автодеплой по пушу может быть не подключён: коммит и push
НЕ означают, что живая ссылка обновилась. Пока автодеплой не работает — после каждого коммита
делай деплой отдельно и присылай подтверждение.

## Незыблемое
- ЦЕНЫ НЕ ВЫДУМЫВАЮТСЯ. Все числа — только в /src/data/pricing.ts, заглушки помечены
  в файле явным комментарием. Реальные цены присылает заказчик. Не искать в интернете,
  не восстанавливать по памяти, не «прикидывать».
- Расчёт детерминированный: одна формула, одни и те же входные данные дают один и тот же
  результат. Никаких приблизительных оценок и никакого ИИ в расчёте.
- Офлайн — норма, сеть — исключение.
- Контент ≠ код. Города, тексты, фото, цены — только в /src/data. В компонентах контента нет.
- Одна рука, улица, спешка. Тач-зоны ≥56 px по высоте. Минимум ввода, максимум тапа.
- Итоговая сумма видна всегда, на любом шаге ввода.
- Факты о местах — адреса, часы, звёздность, цены — не сочиняются. Нет данных: метка и вопрос ЛПР.
- Демоданные — только за флагом FEATURE_DEMO, по умолчанию выключены. Слова «демо» в интерфейсе нет.

## Порядок работы
1. git status в начале задачи. Грязное дерево — сначала разобраться.
2. Разведка → короткий план → правка → показать диф → коммит по отмашке ЛПР → push → деплой.
3. В отчёте: хэш коммита, что затронуто, ссылка на прод. Одна строка на действие, без дампов.
4. Проверять на живом адресе по корню «/», в реальном размере экрана, реальным путём
   пользователя — а не подстановкой состояния.
5. Каждый коммит в теле называет, какие ДРУГИЕ экраны он затрагивает.
6. Находка посреди задачи не разворачивает работу: назвать одной строкой и продолжать.
7. Настройки аккаунтов (Vercel, GitHub) сам не меняешь — называешь ЛПР ссылку и что нажать.

## Запрещено без прямой отмашки
- Менять формулу расчёта или структуру pricing.ts.
- Добавлять внешние сервисы, аналитику, трекеры, карты, платные ключи.
- Класть ключи и токены в репозиторий.
- Ставить тяжёлые библиотеки ради одного эффекта.
