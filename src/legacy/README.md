# Отложенный код: свободный конструктор

Здесь лежит режим, который работал до перехода на пакетные туры.
**Код не удалён и не переписан** — он снят с экрана целиком, чтобы вернуться
вторым режимом, когда заказчик этого захочет.

Из сборки и проверки типов папка выключена: `tsconfig.app.json`, поле `exclude`.
Vite её тоже не тянет — на неё никто не ссылается.

## Что здесь

| Файл | Что делал |
|---|---|
| `CalcView.constructor.vue` | Главный экран конструктора: города, календари, тариф в каждом городе |
| `CityCard.vue` | Карточка города в трёх состояниях: без дат, свёрнутая, раскрытая |
| `DateRangeSheet.vue` | Календарь диапазона дат по одному городу, с блокировкой занятых ночей |

## Что осталось в живом коде и работает на оба режима

- `calculate()` и `cityCost()` в `src/composables/calc.ts` — расчёт по городам
  с округлением цены КАЖДОГО города. Рядом лежит `calculatePackage()` — расчёт
  пакета с одним округлением на весь тур.
- В `src/stores/trip.ts` — `ranges`, `levels`, `busyNights()`, `transferKind()`,
  `previousCity()`, `setRange()`, `clearRange()`, `setLevel()`. Это состояние
  и блокировка пересечений дат; пакетный режим их не читает.
- `TariffCarousel.vue` — общий для обоих режимов. Цену он больше не считает
  сам, а получает функцией в пропсе: конструктор передавал цену города,
  пакетный режим передаёт цену тура.

## Чего здесь нет и почему

Ничего не выброшено. Единственное изменение против прежнего кода —
`TariffCarousel` получает цену снаружи. Прежний вызов сохранён
в `CityCard.vue` и работает без правок.
